## Projects

**[Market Research & BRD Generator](https://github.com/Kashish415/Market-Research-BRD-Generator)** · [Live Demo](https://market-research-agent-crewai.onrender.com/)

A CrewAI-based workflow for market research, competitor analysis, customer insights, requirements analysis and automated BRD generation. Uses Exa MCP for web research and generates editable Word documents.

**[GATE CS Agent](https://github.com/Kashish415/Gate-CS-Agent)** · [Telegram](https://t.me/gate_cs_daily)

A LangGraph pipeline that generates, verifies and publishes three GATE CS questions daily through Telegram using GitHub Actions. Includes DeepEval-based evaluation and LangSmith observability.

**[PawsPalConnect](https://huggingface.co/spaces/kashishgupta/PawsPalConnect_upgraded_nutrition_API)**

An AI-based pet nutrition planning application that generates personalised recommendations using a veterinary knowledge base.

**[ComicCrafter AI](https://github.com/Kashish415/ComicCrafter-AI)**

A prompt-to-comic application that uses LLM-generated scene descriptions and Stable Diffusion for multi-panel image generation.

**[Real-Time Yoga Pose Classifier](https://github.com/Kashish415/YOGA-POSE-DETECTION-AND-CLASSIFICATION)**

A real-time webcam-based pose classification system using MediaPipe landmarks and a Keras model.
